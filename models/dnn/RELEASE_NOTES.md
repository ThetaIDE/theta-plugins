# 1.2.0

Package format v3 (`storage_version: 3`) with host imports from the Theta SDK only. Requires an IDE that reads storage-v3 packages. Selectors and defaults are unchanged.

# DNN 1.1.0

shared_features=false provides independent policy/value feature networks; the default remains shared for checkpoint compatibility. All advertised activations are implemented and unknown activations are rejected.
